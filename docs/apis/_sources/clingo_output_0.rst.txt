``decode/6``
^^^^^^^^^^^^

Decodes CLI JSON and process metadata into a collected ``clingo_result(Status, Models, Properties)`` term.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``decode(Codes,RawStatus,NormalizedStatus,Diagnostics,SourceMap,Result)``
| **Mode and number of proofs:**
|    ``decode(+list(integer),+term,+compound,+list(integer),+list(compound),-compound)`` - ``one_or_error``

| **Exceptions:**
|    An input is insufficiently instantiated:
|        ``instantiation_error``
|    A code-list input is not a character-code list:
|        ``type_error(codes,Input)``
|    ``SourceMap`` is not a list:
|        ``type_error(list,SourceMap)``
|    ``Codes`` does not contain parsable JSON:
|        ``domain_error(json,codes(Codes))``
|    A JSON field has an invalid type or value:
|        ``domain_error(clingo_output,Field-Value)``
|    The JSON simultaneously reports a time limit and another interruption:
|        ``domain_error(clingo_output,interruption_flags)``
|    The process status is fatal or inconsistent with the solver result:
|        ``domain_error(clingo_process_status,NormalizedStatus)``
|    A shown value is not a supported symbol:
|        ``domain_error(clingo_symbol,Codes)``
|    A numeric symbol cannot be represented as an integer:
|        ``representation_error(clingo_integer)``
