``decode/5``
^^^^^^^^^^^^

Decodes CLI JSON-stream output and process metadata into a collected ``minizinc_result(Status, Solutions, Properties)`` term.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``decode(Codes,RawStatus,NormalizedStatus,Diagnostics,Result)``
| **Mode and number of proofs:**
|    ``decode(+list(code),+term,+compound,+list(code),-compound)`` - ``one_or_error``

| **Exceptions:**
|    ``Codes`` is a partial list or a list with an element ``Element`` which is a variable:
|        ``instantiation_error``
|    ``Codes`` is neither a partial list nor a list of character codes:
|        ``type_error(codes,Codes)``
|    A ``--json-stream`` line is not valid JSON:
|        ``domain_error(minizinc_output,json-Line)``
|    A JSON message field has an invalid type or value:
|        ``domain_error(minizinc_output,Field-Value)``
|    A JSON message is missing a required field:
|        ``domain_error(minizinc_output,Field-missing)``
|    ``RawStatus`` is not a ground term:
|        ``instantiation_error``
|    ``NormalizedStatus`` is not a ground term:
|        ``instantiation_error``
|    ``NormalizedStatus`` is not ``exit(0)`` and no JSON-stream message was produced:
|        ``domain_error(minizinc_process_status,NormalizedStatus)``
|    ``Diagnostics`` is a partial list or a list with an element ``Element`` which is a variable:
|        ``instantiation_error``
|    ``Diagnostics`` is neither a partial list nor a list of character codes:
|        ``type_error(codes,Diagnostics)``
