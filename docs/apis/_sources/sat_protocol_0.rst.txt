``sat_protocol``

.. index:: solve/2
.. _sat_protocol/0::solve/2:

``solve/2``
^^^^^^^^^^^

Solves a source with default options using the external SAT solver CLI and returns a collected result after cleanup. Valid sources are ``object(Object)``, ``terms(Statements)``, ``codes(Codes)``, and ``file(Path)``.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``solve(Source,Result)``
| **Mode and number of proofs:**
|    ``solve(+compound,-compound)`` - ``one_or_error``

| **Exceptions:**
|    ``Source`` is not a ground term:
|        ``instantiation_error``
|    ``Source`` is ground but not a supported source, or is ``object(Object)`` where ``Object`` does not implement ``sat_problem_protocol``:
|        ``domain_error(sat_source,Source)``
|    ``Statements`` is ground but not a list:
|        ``type_error(list,Statements)``
|    A statement enumerated by the provider object is not a valid statement:
|        ``domain_error(sat_statement,Statement)``
|    An origin enumerated by the provider object is invalid, or its origins and statements differ in length:
|        ``domain_error(sat_origins,Origins)``
|    ``Codes`` is ground but not a list of character codes:
|        ``type_error(codes,Codes)``
|    An element ``Code`` of the list ``Codes`` is ground but not an integer:
|        ``type_error(integer,Code)``
|    An element ``Code`` of the list ``Codes`` is an integer but not a valid character code:
|        ``domain_error(character_code,Code)``
|    ``Path`` is ground but not an atom:
|        ``type_error(atom,Path)``
|    ``Path`` does not exist:
|        ``existence_error(source_sink,Path)``
|    ``Path`` cannot be opened for reading:
|        ``permission_error(open,source_sink,Path)``
|    A launcher argument contains a null character:
|        ``domain_error(sat_shell_argument,Argument)``
|    The selected solver executable or a shell dependency does not exist:
|        ``existence_error(command,Command)``
|    An owned directory cannot be found during cleanup:
|        ``existence_error(directory,Directory)``
|    An owned file or directory cannot be removed:
|        ``permission_error(delete,source_sink,Path)``
|    A character sequence is not valid UTF-8:
|        ``representation_error(utf_8)``
|    A launcher operation fails:
|        ``sat_transport(Stage,Status,Details)``
|    Solver output is invalid or inconsistent with its exit status:
|        ``sat_solver_error(Formal,Status,Diagnostics,SourceMap)``

``literal/2``
^^^^^^^^^^^^^

Enumerates, by backtracking, the collected model literals (``+Term`` or ``-Term``) without starting a process. Fails when the result has no witness.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``literal(Result,Literal)``
| **Mode and number of proofs:**
|    ``literal(+compound,-compound)`` - ``zero_or_more``

| **Exceptions:**
|    ``Result`` is not a ground term:
|        ``instantiation_error``
|    ``Result`` is not a valid collected SAT solver result:
|        ``domain_error(sat_result,Result)``
