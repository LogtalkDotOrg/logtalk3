**protocol**

``sat_protocol``
================

Protocol for process-backed Kissat, CaDiCaL, Glucose, and Z3 CLI solving, source generation, and result inspection.

|    ``logtalk_load(sat(loader))``

.. index:: solve/2
.. _sat_protocol/0::solve/2:

``solve/2``
^^^^^^^^^^^

Solves a source with default options using the external SAT solver CLI and returns a collected result after cleanup.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``solve(Source,Result)``
| **Mode and number of proofs:**
|    ``solve(+compound,-compound)`` - ``one_or_error``

| **Exceptions:**
|    ``Source`` or a provider statement is insufficiently instantiated:
|        ``instantiation_error``
|    A source list has an invalid type:
|        ``type_error(list,Input)``
|    ``Codes`` is not a character-code list:
|        ``type_error(codes,Codes)``
|    ``Path`` is not an atom:
|        ``type_error(atom,Path)``
|    ``Source`` is not supported:
|        ``domain_error(sat_source,Source)``
|    A provider statement is invalid:
|        ``domain_error(sat_statement,Statement)``
|    A provider origin is invalid:
|        ``domain_error(sat_origins,Origins)``
|    A launcher argument contains a null character:
|        ``domain_error(sat_shell_argument,Argument)``
|    The selected solver or a shell dependency cannot be resolved:
|        ``existence_error(command,Command)``
|    A source or capture file cannot be accessed:
|        ``existence_error(source_sink,Path)``
|    A source or capture file cannot be opened:
|        ``permission_error(open,source_sink,Path)``
|    An owned directory cannot be found during cleanup:
|        ``existence_error(directory,Directory)``
|    An owned file or directory cannot be removed:
|        ``permission_error(delete,source_sink,Path)``
|    A character sequence is not valid UTF-8:
|        ``representation_error(utf_8)``
|    A launcher operation fails:
|        ``sat_transport(Stage,Status,Details)``
|    Solver output is invalid or inconsistent with its exit status:
|        ``sat_solver_error(Formal,Status,Diagnostics,SourceMap)``

``program/1``
^^^^^^^^^^^^^

Generates and prints DIMACS CNF source to the current output, equivalent to ``program/2`` followed by ``print_program/1``, without invoking the solver.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``program(Source)``
| **Mode and number of proofs:**
|    ``program(+compound)`` - ``one_or_error``

| **Exceptions:**
|    ``Source`` or a provider statement is insufficiently instantiated:
|        ``instantiation_error``
|    ``Statements`` is not a list:
|        ``type_error(list,Statements)``
|    ``Codes`` is not a character-code list:
|        ``type_error(codes,Codes)``
|    A character code is not an integer:
|        ``type_error(integer,Code)``
|    ``Path`` is not an atom:
|        ``type_error(atom,Path)``
|    ``Source`` is not a supported source or its object does not implement the provider protocol:
|        ``domain_error(sat_source,Source)``
|    A provider statement is invalid:
|        ``domain_error(sat_statement,Statement)``
|    A provider origin is invalid:
|        ``domain_error(sat_origins,Origins)``
|    ``Path`` does not exist:
|        ``existence_error(source_sink,Path)``
|    ``Path`` cannot be opened for reading:
|        ``permission_error(open,source_sink,Path)``
|    The current output stream does not allow writing:
|        ``permission_error(output,stream,Stream)``

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``print_program(Codes)``
| **Mode and number of proofs:**
|    ``print_program(+list(integer))`` - ``one_or_error``

|    ``Codes`` is insufficiently instantiated:
|        ``instantiation_error``
|    ``Codes`` is not a character-code list:
|        ``type_error(codes,Codes)``
|    A character code is not an integer:
|        ``type_error(integer,Code)``
|    A character code is outside the supported range:
|        ``domain_error(character_code,Code)``
|    The current output stream does not allow writing:
|        ``permission_error(output,stream,Stream)``

``literal/2``
^^^^^^^^^^^^^

Enumerates, by backtracking, the collected model literals (``pos(Term)`` or ``neg(Term)``) without starting a process. Fails when the result has no witness.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``literal(Result,Literal)``
| **Mode and number of proofs:**
|    ``literal(+compound,-compound)`` - ``zero_or_more``

| **Exceptions:**
|    ``Result`` is insufficiently instantiated:
|        ``instantiation_error``
|    ``Result`` is not a collected SAT solver result:
|        ``domain_error(sat_result,Result)``
