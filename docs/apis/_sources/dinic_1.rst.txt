**object**

``dinic(Dictionary)``
=====================

* ``Dictionary`` - Dictionary object used by the flow network (e.g., ``avltree``).


Dinic maximum flow algorithm. Each phase builds a level graph using breadth-first search and then computes a blocking flow using depth-first search. Runs in O(V^2*E) time. A vertex whose depth-first search fails to push the requested amount is recorded as dead for the rest of the phase, which plays the role of the current-arc pointers of imperative implementations.
