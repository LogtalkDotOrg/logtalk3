**object**

``variance_score``
==================

Unsupervised feature scoring by population variance: ignores Targets entirely. A near-constant feature (one that takes almost the same value in every example) carries little information for distinguishing examples and so scores low; this is the classic "variance threshold" filter criterion. Scores 0.0 when every value is missing.
