.. index:: serialize/2
.. _asp_program/0::serialize/2:

``serialize/2``
^^^^^^^^^^^^^^^

Serializes ground canonical ASP statements to character codes.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``serialize(Statements,Codes)``
| **Mode and number of proofs:**
|    ``serialize(+list,-list(integer))`` - ``one_or_error``

| **Exceptions:**
|    ``Statements`` is a partial list or a list with an element ``Statement`` which is a variable:
|        ``instantiation_error``
|    ``Statements`` is neither a partial list nor a list:
|        ``type_error(list,Statements)``
|    An element ``Statement`` of the list ``Statements`` is not a valid statement:
|        ``domain_error(asp_statement,Statement)``

.. index:: serialize/4

``serialize/4``
^^^^^^^^^^^^^^^

Serializes statements with origins and returns ``line(Start, End, Origin)`` source-map entries.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``serialize(Statements,Origins,Codes,SourceMap)``
| **Mode and number of proofs:**
|    ``serialize(+list,+list,-list(code),-list(compound))`` - ``one_or_error``

| **Exceptions:**
|    ``Statements`` is a partial list or a list with an element ``Statement`` which is a variable:
|        ``instantiation_error``
|    ``Statements`` is neither a partial list nor a list:
|        ``type_error(list,Statements)``
|    An element ``Statement`` of the list ``Statements`` is not a valid statement:
|        ``domain_error(asp_statement,Statement)``
|    ``Origins`` is a partial list or a list with an element ``Origin`` which is a variable:
|        ``instantiation_error``
|    ``Origins`` is neither a variable nor a list:
|        ``type_error(list,Origins)``
|    ``Origins`` has an element that is neither ``unknown`` nor a valid ``source(File, Start, End)`` term, or its length differs from ``Statements``:
|        ``domain_error(asp_origins,Origins)``
