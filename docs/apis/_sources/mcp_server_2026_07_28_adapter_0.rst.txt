``mcp_server_2026_07_28_adapter``
=================================

MCP 2026-07-28 specification adapter. Synchronous request engine over stdio. Implements discovery, tools/prompts/resources, multi-round tool results (MRTR), caching, progress, and subscriptions. Cancellation of ``subscriptions/listen`` is supported when ``notifications/cancelled`` is read after the listen acknowledgment; mid-request cancellation of ordinary calls is best-effort only under synchronous dispatch. Never writes JSON-RPC requests to stdout.
