``decode_entities_codes/4``
^^^^^^^^^^^^^^^^^^^^^^^^^^^

Decodes semicolon-terminated numeric and profile-defined named character references. The unknown-name policy is ``preserve`` or ``error``.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``decode_entities_codes(Codes,Profile,Unknown,Decoded)``
| **Mode and number of proofs:**
|    ``decode_entities_codes(+list(integer),+object_identifier,+atom,-list(integer))`` - ``one_or_error``

| **Exceptions:**
|    A numeric reference denotes a value that is not a Unicode scalar value:
|        ``domain_error(unicode_scalar_value,Value)``
|    A named reference is unknown and the policy is ``error``:
|        ``domain_error(character_reference,Reference)``
