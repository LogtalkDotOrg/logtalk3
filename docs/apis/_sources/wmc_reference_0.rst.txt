**object**

``wmc_reference``
=================

Reference weighted model counter written in Logtalk (no external solver required): DPLL with unit propagation, connected component decomposition, and free variable handling over DIMACS CNF source with Model Counting Competition weights. Intended for small problems and as an oracle for testing; use an external counter for larger problems.

``count/2``
^^^^^^^^^^^

Computes the weighted model count of CNF source (``p cnf`` header, ``c p weight`` lines, and clauses), which is an integer when all weights are integers. Weights default to 1.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``count(Codes,Count)``
| **Mode and number of proofs:**
|    ``count(+list(code),-number)`` - ``one_or_error``

| **Exceptions:**
|    ``Codes`` is a partial list or a list with an element ``Element`` which is a variable:
|        ``instantiation_error``
|    ``Codes`` is neither a partial list nor a list of character codes:
|        ``type_error(codes,Codes)``
|    The source is not valid CNF source:
|        ``domain_error(wmc_source,Line)``
