.. index:: solve/2
.. _souffle_protocol/0::solve/2:

``solve/2``
^^^^^^^^^^^

Solves a source with default options using the external Souffle CLI and returns a collected result after cleanup. Valid sources are ``object(Object)``, ``terms(Statements)``, ``codes(Codes)``, and ``file(Path)``. No ``.output``/``.printsize`` relations are decoded unless requested via the ``outputs/1``/``printsizes/1`` options of ``solve/3``.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``solve(Source,Result)``
| **Mode and number of proofs:**
|    ``solve(+compound,-compound)`` - ``one_or_error``

| **Exceptions:**
|    ``Source`` is not ground:
|        ``instantiation_error``
|    ``Source`` is ground but not a supported source, or is ``object(Object)`` where ``Object`` does not implement ``souffle_problem_protocol``:
|        ``domain_error(souffle_source,Source)``
|    ``Statements`` is ground but not a list:
|        ``type_error(list,Statements)``
|    A statement enumerated by the provider object is not a valid statement:
|        ``domain_error(souffle_statement,Statement)``
|    An origin enumerated by the provider object is invalid, or its origins and statements differ in length:
|        ``domain_error(souffle_origins,Origins)``
|    ``Codes`` is ground but not a list of character codes:
|        ``type_error(codes,Codes)``
|    An element ``Code`` of the list ``Codes`` is ground but not an integer:
|        ``type_error(integer,Code)``
|    An element ``Code`` of the list ``Codes`` is an integer but not a valid character code:
|        ``domain_error(character_code,Code)``
|    ``Path`` is ground but not an atom:
|        ``type_error(atom,Path)``
|    ``Path`` does not exist:
|        ``existence_error(source_sink,Path)``
|    ``Path`` cannot be opened for reading:
|        ``permission_error(open,source_sink,Path)``
|    A launcher argument contains a null character:
|        ``domain_error(souffle_shell_argument,Argument)``
|    The ``souffle`` executable or a shell dependency does not exist:
|        ``existence_error(command,Command)``
|    An owned directory cannot be found during cleanup:
|        ``existence_error(directory,Directory)``
|    An owned file or directory cannot be removed:
|        ``permission_error(delete,source_sink,Path)``
|    A character sequence is not valid UTF-8:
|        ``representation_error(utf_8)``
|    A launcher operation fails:
|        ``souffle_transport(Stage,Status,Details)``
|    Solver output is invalid or inconsistent with its exit status:
|        ``souffle_solver_error(Formal,Status,Diagnostics,SourceMap)``

``solve/3``
^^^^^^^^^^^

Solves a source using executable, parallelism, warning, compilation, EDB facts, and decoded-relation options. Repeated options use the first occurrence. Valid sources are ``object(Object)``, ``terms(Statements)``, ``codes(Codes)``, and ``file(Path)``. The ``outputs/1`` option lists which ``.output`` relations to decode and their column types; the ``printsizes/1`` option lists which ``.printsize`` relations to decode.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``solve(Source,Result,Options)``
| **Mode and number of proofs:**
|    ``solve(+compound,-compound,+list(compound))`` - ``one_or_error``

| **Exceptions:**
|    ``Source`` is not ground:
|        ``instantiation_error``
|    ``Source`` is ground but not a supported source, or is ``object(Object)`` where ``Object`` does not implement ``souffle_problem_protocol``:
|        ``domain_error(souffle_source,Source)``
|    ``Statements`` is ground but not a list:
|        ``type_error(list,Statements)``
|    A statement enumerated by the provider object is not a valid statement:
|        ``domain_error(souffle_statement,Statement)``
|    An origin enumerated by the provider object is invalid, or its origins and statements differ in length:
|        ``domain_error(souffle_origins,Origins)``
|    ``Codes`` is ground but not a list of character codes:
|        ``type_error(codes,Codes)``
|    An element ``Code`` of the list ``Codes`` is ground but not an integer:
|        ``type_error(integer,Code)``
|    An element ``Code`` of the list ``Codes`` is an integer but not a valid character code:
|        ``domain_error(character_code,Code)``
|    ``Path`` is ground but not an atom:
|        ``type_error(atom,Path)``
|    ``Path`` does not exist:
|        ``existence_error(source_sink,Path)``
|    ``Path`` cannot be opened for reading:
|        ``permission_error(open,source_sink,Path)``
|    ``Options`` is a variable:
|        ``instantiation_error``
|    ``Options`` is neither a variable nor a list:
|        ``type_error(list,Options)``
|    An element ``Option`` of the list ``Options`` is a variable:
|        ``instantiation_error``
|    An element ``Option`` of the list ``Options`` is neither a variable nor a compound term:
|        ``type_error(compound,Option)``
|    An element ``Option`` of the list ``Options`` is a compound term but not a valid option:
|        ``domain_error(option,Option)``
|    Both ``facts/1`` and ``facts_data/1`` are given with non-default values:
|        ``domain_error(souffle_facts_option,facts(Path)-facts_data(Pairs))``
|    An element of ``facts_data/1`` has a symbol column value containing a tab or newline character, or a value that is not an integer, float, or atom:
|        ``domain_error(souffle_facts_value,Value)``
|    A launcher argument contains a null character:
|        ``domain_error(souffle_shell_argument,Argument)``
|    The ``souffle`` executable or a shell dependency does not exist:
|        ``existence_error(command,Command)``
|    An owned directory cannot be found during cleanup:
|        ``existence_error(directory,Directory)``
|    An owned file or directory cannot be removed:
|        ``permission_error(delete,source_sink,Path)``
|    A character sequence is not valid UTF-8:
|        ``representation_error(utf_8)``
|    A launcher operation fails:
|        ``souffle_transport(Stage,Status,Details)``
|    Solver output is invalid or inconsistent with its exit status:
|        ``souffle_solver_error(Formal,Status,Diagnostics,SourceMap)``

``relation/4``
^^^^^^^^^^^^^^

Enumerates, by backtracking, decoded ``.output`` relations collected in a result: the relation name, its requested column types, and its rows (each row a list of decoded Prolog values, one per column).

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``relation(Result,Name,Columns,Rows)``
| **Mode and number of proofs:**
|    ``relation(+compound,?atom,?list(atom),?list(list))`` - ``zero_or_more``

| **Exceptions:**
|    ``Result`` is not ground:
|        ``instantiation_error``
|    ``Result`` is not a valid collected Souffle result:
|        ``domain_error(souffle_result,Result)``
