**object**

``correlation_score``
=====================

Scores a numeric feature against a numeric target using squared Pearson correlation over complete examples. Returns a score in [0.0, 1.0], independent of correlation sign. Returns 0.0 for fewer than two complete examples or an exactly constant feature or target.
