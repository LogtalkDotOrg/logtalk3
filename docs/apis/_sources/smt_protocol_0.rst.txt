**protocol**

``smt_protocol``
================

Protocol for process-backed Z3, cvc5, Bitwuzla, and Yices 2 CLI solving, SMT-LIB 2 source generation, and collected result inspection.

| **Availability:** 
|    ``logtalk_load(smt(loader))``

| **Author:** Paulo Moura
| **Version:** 1:0:0
| **Date:** 2026-11-08

| **Compilation flags:**
|    ``static``


| **Dependencies:**

.. index:: solve/2
.. _smt_protocol/0::solve/2:

``solve/2``
^^^^^^^^^^^

Solves a source with default options using the external SMT solver CLI and returns a collected result per ``check-sat`` command, in script order, after cleanup.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``solve(Source,Results)``
| **Mode and number of proofs:**
|    ``solve(+compound,-list(compound))`` - ``one_or_error``

| **Exceptions:**
|    ``Source`` or a provider statement is insufficiently instantiated:
|        ``instantiation_error``
|    A source list has an invalid type:
|        ``type_error(list,Input)``
|    ``Source`` is not supported:
|        ``domain_error(smt_source,Source)``
|    A launcher operation fails:
|        ``smt_transport(Stage,Status,Details)``
|    Solver output is invalid or inconsistent with its exit status:
|        ``smt_solver_error(Formal,Status,Diagnostics,SourceMap)``

``solve/3``
^^^^^^^^^^^

Solves a source using ``solver/1``, ``executable/1``, and ``time_limit/1`` options. Repeated options use the first occurrence.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``solve(Source,Results,Options)``
| **Mode and number of proofs:**
|    ``solve(+compound,-list(compound),+list(compound))`` - ``one_or_error``

| **Exceptions:**
|    An input is insufficiently instantiated:
|        ``instantiation_error``
|    A source or options list has an invalid type:
|        ``type_error(list,Input)``
|    An option is not a compound term:
|        ``type_error(compound,Option)``
|    ``Codes`` is not a character-code list:
|        ``type_error(codes,Codes)``
|    ``Path`` is not an atom:
|        ``type_error(atom,Path)``
|    ``Source`` is not supported:
|        ``domain_error(smt_source,Source)``
|    A provider statement is invalid:
|        ``domain_error(smt_statement,Statement)``
|    A provider origin is invalid:
|        ``domain_error(smt_origins,Origins)``
|    An option is invalid:
|        ``domain_error(option,Option)``
|    A launcher argument contains a null character:
|        ``domain_error(smt_shell_argument,Argument)``
|    The selected solver or a shell dependency cannot be resolved:
|        ``existence_error(command,Command)``
|    A source or capture file cannot be accessed:
|        ``existence_error(source_sink,Path)``
|    A source or capture file cannot be opened:
|        ``permission_error(open,source_sink,Path)``
|    An owned directory cannot be found during cleanup:
|        ``existence_error(directory,Directory)``
|    An owned file or directory cannot be removed:
|        ``permission_error(delete,source_sink,Path)``
|    A character sequence is not valid UTF-8:
|        ``representation_error(utf_8)``
|    A launcher operation fails:
|        ``smt_transport(Stage,Status,Details)``
|    Solver output is invalid or inconsistent with its exit status:
|        ``smt_solver_error(Formal,Status,Diagnostics,SourceMap)``

.. index:: capability/2
.. _smt_protocol/0::capability/2:

``capability/2``
^^^^^^^^^^^^^^^^

Enumerates, by backtracking, advisory ``Solver``-``Feature`` capability pairs. Purely informational: the library does not enforce these pairs and a solver call may still succeed, fail, or report ``unknown`` for a feature outside this table.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``capability(Solver,Feature)``
| **Mode and number of proofs:**
|    ``capability(?atom,?atom)`` - ``zero_or_more``

| **Remarks:**

    - Feature: One of ``quantifiers``, ``strings``, ``linear_arithmetic``, ``non_linear_arithmetic``, ``unsat_cores``, ``incremental``, ``bit_vectors``, ``arrays``, ``floating_point``, or ``algebraic_datatypes``.
