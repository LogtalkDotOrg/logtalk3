``local_encrypt_with_nonce/6``
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

Encrypts a local payload using an explicit 32-byte nonce. Intended for deterministic conformance tests; production callers must use local_encrypt/3 or local_encrypt/5.
