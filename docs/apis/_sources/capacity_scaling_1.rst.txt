**object**

``capacity_scaling(Dictionary)``
================================

* ``Dictionary`` - Dictionary object used by the flow network.


Capacity-scaling augmenting paths. Each phase traverses residual arcs with capacity at least a power-of-two threshold. The standard bound is O(E^2*log(U)), before dictionary costs. This is an alternative to Dinic, not a guaranteed speedup.
