``linear_programming_cli``
==========================

Support for linear programming backends that run an external solver command-line tool: the problem is written using the CPLEX LP format, the solver is run in an isolated directory, and its output is decoded into a result term. Importing objects must define the ``solver_name/1``, ``default_executable/1``, ``solver_arguments/2``, and ``decode_output/6`` protected predicates.

.. index:: decode_output/6
.. _linear_programming_cli/0::decode_output/6:

``decode_output/6``
^^^^^^^^^^^^^^^^^^^

Decodes the solver standard output and solution file contents into a status (``optimal``, ``feasible``, ``infeasible``, ``unbounded``, ``infeasible_or_unbounded``, ``time_limit``, ``iteration_limit``, ``node_limit``, or ``numerical_error``), an objective value (or ``none``), solution data represented as ``solution(Pairs)`` when a solution section was parsed or ``none`` otherwise, and the status text reported by the solver. The pairs use the one-based variable index; absent variables in a parsed solution have value zero.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``decode_output(Output,Solution,Status,Objective,SolutionData,Text)``
| **Mode and number of proofs:**
|    ``decode_output(+list(code),+list(code),-atom,-term,-term,-atom)`` - ``one_or_error``

| **Exceptions:**
|    The solver output is missing required data or cannot be decoded:
|        ``domain_error(linear_programming_output,Reason)``

``assemble_result/9``
^^^^^^^^^^^^^^^^^^^^^

Assembles a validated result from already decoded solver data.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``assemble_result(Solver,Problem,RawStatus,NormalizedStatus,Status,ReportedObjective,SolutionData,Text,Result)``
| **Mode and number of proofs:**
|    ``assemble_result(+atom,+compound,+term,+compound,+atom,+term,+term,+atom,-compound)`` - ``one_or_error``

| **Exceptions:**
|    An ``optimal`` or ``feasible`` result has no complete decoded solution:
|        ``domain_error(linear_programming_output,missing_solution)``
|    The decoded solution is inconsistent with the problem or objective:
|        ``domain_error(linear_programming_output,inconsistent_solution)``
