.. index:: learn/3
.. _forecaster_protocol/0::learn/3:

``learn/3``
^^^^^^^^^^^

Learns a forecasting model from the given time series dataset object using the specified options.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``learn(Dataset,Forecaster,Options)``
| **Mode and number of proofs:**
|    ``learn(+object_identifier,-compound,+list(compound))`` - ``one_or_error``

| **Exceptions:**
|    ``Dataset`` is a variable:
|        ``instantiation_error``
|    ``Dataset`` is neither a variable nor a valid object identifier:
|        ``type_error(object_identifier,Dataset)``
|    ``Dataset`` is a valid object identifier but not an existing object:
|        ``existence_error(object,Dataset)``
|    ``Options`` is a variable:
|        ``instantiation_error``
|    ``Options`` is neither a variable nor a list:
|        ``type_error(list,Options)``
|    An element ``Option`` of the list ``Options`` is a variable:
|        ``instantiation_error``
|    An element ``Option`` of the list ``Options`` is neither a variable nor a compound term:
|        ``type_error(compound,Option)``
|    An element ``Option`` of the list ``Options`` is a compound term but not a valid option:
|        ``domain_error(option,Option)``

.. index:: forecast/3
.. _forecaster_protocol/0::forecast/3:

``forecast/3``
^^^^^^^^^^^^^^

Forecasts the next ``Horizon`` values beyond the training series using the learned forecasting model. A zero horizon returns an empty list.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``forecast(Forecaster,Horizon,Forecasts)``
| **Mode and number of proofs:**
|    ``forecast(+compound,+non_negative_integer,-list(number))`` - ``one_or_error``

| **Exceptions:**
|    ``Forecaster`` is a variable:
|        ``instantiation_error``
|    ``Forecaster`` is not a valid forecaster:
|        ``domain_error(forecaster,Forecaster)``
|    ``Horizon`` is a variable:
|        ``instantiation_error``
|    ``Horizon`` is neither a variable nor an integer:
|        ``type_error(integer,Horizon)``
|    ``Horizon`` is an integer but is negative:
|        ``domain_error(non_negative_integer,Horizon)``

``check_forecaster/1``
^^^^^^^^^^^^^^^^^^^^^^

Checks that a learned forecaster term is structurally valid for the receiving implementation. Throws an exception when the term is not a valid forecaster representation.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``check_forecaster(Forecaster)``
| **Mode and number of proofs:**
|    ``check_forecaster(@compound)`` - ``one_or_error``

| **Exceptions:**
|    ``Forecaster`` is a variable:
|        ``instantiation_error``
|    ``Forecaster`` is neither a variable nor a valid forecaster:
|        ``domain_error(forecaster,Forecaster)``

.. index:: export_to_clauses/4
.. _forecaster_protocol/0::export_to_clauses/4:

``export_to_clauses/4``
^^^^^^^^^^^^^^^^^^^^^^^

Converts a forecaster into a list of predicate clauses. ``Functor`` is the functor for the generated predicate clauses. When exporting a serialized forecaster term, a noun such as ``forecaster`` or ``model`` is usually clearer than a verb such as ``forecast``.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``export_to_clauses(Dataset,Forecaster,Functor,Clauses)``
| **Mode and number of proofs:**
|    ``export_to_clauses(+object_identifier,+compound,+atom,-list(clause))`` - ``one_or_error``

| **Exceptions:**
|    ``Forecaster`` or ``Functor`` is a variable:
|        ``instantiation_error``
|    ``Forecaster`` is not a valid baseline forecaster:
|        ``domain_error(forecaster,Forecaster)``
|    ``Functor`` is neither a variable nor an atom:
|        ``type_error(atom,Functor)``

.. index:: export_to_file/4

``export_to_file/4``
^^^^^^^^^^^^^^^^^^^^

Exports a forecaster to a file. ``Functor`` is the functor for the generated predicate clauses. When exporting a serialized forecaster term, a noun such as ``forecaster`` or ``model`` is usually clearer than a verb such as ``forecast``.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``export_to_file(Dataset,Forecaster,Functor,File)``
| **Mode and number of proofs:**
|    ``export_to_file(+object_identifier,+compound,+atom,+atom)`` - ``one_or_error``

| **Exceptions:**
|    ``Forecaster``, ``Functor``, or ``File``:
|        ``instantiation_error``
|    ``Forecaster`` is not a valid forecaster:
|        ``domain_error(forecaster,Forecaster)``
|    ``Functor`` is neither a variable nor an atom:
|        ``type_error(atom,Functor)``
|    ``File`` is not a valid file specification:
|        ``type_error(source_sink,File)``
|    The output location does not exist:
|        ``existence_error(source_sink,File)``
|    The output file cannot be opened:
|        ``permission_error(open,source_sink,File)``
|    The output stream cannot be written to:
|        ``permission_error(output,stream,Stream)``
