``solve/2``
^^^^^^^^^^^

Solves an OMT source with default options and returns one result per check.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``solve(Source,Results)``
| **Mode and number of proofs:**
|    ``solve(+compound,-list(compound))`` - ``one_or_error``


------------

.. index:: solve/3
.. _omt_protocol/0::solve/3:

``solve/3``
^^^^^^^^^^^

Solves with solver/1, executable/1, and time_limit/1 options. OptiMathSAT rejects nonzero time limits.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``solve(Source,Results,Options)``
| **Mode and number of proofs:**
|    ``solve(+compound,-list(compound),+list(compound))`` - ``one_or_error``

| **Exceptions:**
|    An OptiMathSAT time limit is nonzero:
|        ``domain_error(optimathsat_time_limit,Seconds)``
|    Solver output or process status is invalid:
|        ``omt_solver_error(Formal,Status,Diagnostics,SourceMap)``
