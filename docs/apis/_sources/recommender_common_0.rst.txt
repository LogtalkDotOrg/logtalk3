.. index:: dataset_ratings/2
.. _recommender_common/0::dataset_ratings/2:

``dataset_ratings/2``
^^^^^^^^^^^^^^^^^^^^^

Collects ratings with atomic user and item identifiers as ``rating(User, Item, Rating)`` terms. Checks for duplicate user-item pairs and a declared rating count matching the observed count.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``dataset_ratings(Dataset,Ratings)``
| **Mode and number of proofs:**
|    ``dataset_ratings(+object_identifier,-list(compound))`` - ``one_or_error``

| **Exceptions:**
|    The dataset contains no ratings:
|        ``domain_error(non_empty_ratings,Dataset)``
|    A user or item identifier is a variable:
|        ``instantiation_error``
|    A user or item identifier is not atomic:
|        ``type_error(atomic,Identifier)``
|    The same ``User``-``Item`` pair is rated more than once:
|        ``domain_error(duplicate_rating,User-Item)``
|    The declared rating count is a variable:
|        ``instantiation_error``
|    The declared rating count is neither a variable nor an integer:
|        ``type_error(integer,DeclaredCount)``
|    The declared rating count is an integer but is not positive:
|        ``domain_error(positive_integer,DeclaredCount)``
|    The declared and observed rating counts differ:
|        ``consistency_error(rating_count,DeclaredCount,ObservedCount)``

``check_ratings/2``
^^^^^^^^^^^^^^^^^^^

Checks that ratings are non-empty, have atomic user and item identifiers and numeric values, and fall within any declared ``rating_scale/2``.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``check_ratings(Dataset,Ratings)``
| **Mode and number of proofs:**
|    ``check_ratings(+object_identifier,+list(compound))`` - ``one_or_error``

| **Exceptions:**
|    ``Ratings`` is empty:
|        ``domain_error(non_empty_ratings,Dataset)``
|    A user or item identifier is a variable:
|        ``instantiation_error``
|    A user or item identifier is not atomic:
|        ``type_error(atomic,Identifier)``

|        ``type_error(number,Rating)``

|        ``domain_error(rating_scale,Min-Max)``

|        ``domain_error(rating_scale(Min,Max),Rating)``

Scores unrated catalog items using self ``predict_rating/4`` and returns up to ``N`` descending-score pairs; ties use descending standard item order.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``recommend_from_ratings(Recommender,Ratings,User,N,Recommendations)``
| **Mode and number of proofs:**
|    ``recommend_from_ratings(+compound,+list(compound),+atomic,+positive_integer,-list(pair))`` - ``one_or_error``

|        ``instantiation_error``
|    The model is invalid:
|        ``domain_error(recommender,Recommender)``
|    User is not atomic:
|        ``type_error(atomic,User)``
|    N is not an integer:
|        ``type_error(integer,N)``
|    N is not positive:
|        ``domain_error(positive_integer,N)``
