.. index:: serialize/2
.. _sat_program/0::serialize/2:

``serialize/2``
^^^^^^^^^^^^^^^

Serializes ground canonical CNF statements to DIMACS character codes, assigning sequential variable numbers by first occurrence.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``serialize(Statements,Codes)``
| **Mode and number of proofs:**
|    ``serialize(+list(compound),-list(integer))`` - ``one_or_error``

| **Exceptions:**
|    ``Statements`` is insufficiently instantiated:
|        ``instantiation_error``
|    ``Statements`` is not a list:
|        ``type_error(list,Statements)``
|    A statement is invalid:
|        ``domain_error(sat_statement,Statement)``


------------

.. index:: serialize/4
.. _sat_program/0::serialize/4:

``serialize/4``
^^^^^^^^^^^^^^^

Serializes statements with origins and returns ``line(Start, End, Origin)`` source-map entries; the generated header occupies line 1.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``serialize(Statements,Origins,Codes,SourceMap)``
| **Mode and number of proofs:**
|    ``serialize(+list(compound),+list,-list(integer),-list(compound))`` - ``one_or_error``

| **Exceptions:**
|    An input is insufficiently instantiated:
|        ``instantiation_error``
|    An input is not a list:
|        ``type_error(list,Input)``
|    A statement is invalid:
|        ``domain_error(sat_statement,Statement)``
|    An origin is invalid or the list lengths differ:
|        ``domain_error(sat_origins,Origins)``


------------

.. index:: variables/2
.. _sat_program/0::variables/2:

``variables/2``
^^^^^^^^^^^^^^^

Returns the ordered ``Term-Number`` variable table that ``serialize/2`` and ``serialize/4`` assign by first occurrence across clause statements.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``variables(Statements,Variables)``
| **Mode and number of proofs:**
|    ``variables(+list(compound),-list(pair))`` - ``one_or_error``

| **Exceptions:**
|    ``Statements`` is insufficiently instantiated:
|        ``instantiation_error``
|    ``Statements`` is not a list:
|        ``type_error(list,Statements)``
|    A statement is invalid:
|        ``domain_error(sat_statement,Statement)``
