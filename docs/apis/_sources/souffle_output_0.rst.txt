``decode/8``
^^^^^^^^^^^^

Decodes captured stdout, stderr, per-relation CSV file content, and process metadata into a collected ``souffle_result(Relations, Sizes, Properties)`` term.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``decode(Codes,Diagnostics,RelationCodes,RawStatus,NormalizedStatus,Outputs,Printsizes,Result)``
| **Mode and number of proofs:**
|    ``decode(+list(code),+list(code),+list(compound),+term,+compound,+list(pair),+list(atom),-compound)`` - ``one_or_error``

| **Exceptions:**
|    ``Codes`` is a partial list or a list with an element ``Element`` which is a variable:
|        ``instantiation_error``
|    ``Codes`` is neither a partial list nor a list of character codes:
|        ``type_error(codes,Codes)``
|    ``Diagnostics`` is a partial list or a list with an element ``Element`` which is a variable:
|        ``instantiation_error``
|    ``Diagnostics`` is neither a partial list nor a list of character codes:
|        ``type_error(codes,Diagnostics)``
|    ``RelationCodes``, ``Outputs``, or ``Printsizes`` is a partial list or has a variable element:
|        ``instantiation_error``
|    ``RelationCodes``, ``Outputs``, or ``Printsizes`` is neither a partial list nor a list:
|        ``type_error(list,RelationCodes)``
|    ``RawStatus`` is not ground:
|        ``instantiation_error``
|    ``NormalizedStatus`` is not ground:
|        ``instantiation_error``
|    ``NormalizedStatus`` is not ``exit(0)``:
|        ``domain_error(souffle_process_status,NormalizedStatus)``
|    A requested relation in ``Outputs`` has no entry, or a ``missing`` entry, in ``RelationCodes``:
|        ``domain_error(souffle_output,Name-missing)``
|    A CSV row for a requested relation has a different number of columns than declared in ``Outputs``:
|        ``domain_error(souffle_output,column_count-(Row-Types))``
|    A ``number`` or ``unsigned`` column value is not a valid integer, or an ``unsigned`` value is negative:
|        ``domain_error(souffle_output,Type-Value)``
|    A ``float`` column value is not a valid number:
|        ``domain_error(souffle_output,float-Value)``
|    A requested relation in ``Printsizes`` has no matching ``Name\tCount`` line in ``Codes``:
|        ``domain_error(souffle_output,Name-missing)``
