**object**

``lp_format``
=============

Generates CPLEX LP format source (understood by GLPK, CBC, HiGHS, SCIP, and most other solvers) from ``linear_program/3`` problems. Variables are written using the generated names ``x1``, ``x2``, ... in declaration order (all variables are listed in the objective, with a zero coefficient if necessary, to keep them and their order), constraints as ``c1``, ``c2``, ..., and the objective as ``obj``.

| **Availability:** 
|    ``logtalk_load(linear_programming(loader))``

``generate/2``
