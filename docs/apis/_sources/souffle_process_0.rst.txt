.. index:: quote/3

``quote/3``
^^^^^^^^^^^

Quotes an atom as one POSIX shell or Windows PowerShell literal, without interpolation.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``quote(Platform,Argument,Quoted)``
| **Mode and number of proofs:**
|    ``quote(+atom,+atom,-atom)`` - ``one_or_error``

| **Exceptions:**
|    ``Platform`` is a variable:
|        ``instantiation_error``
|    ``Argument`` is a variable:
|        ``instantiation_error``
|    ``Platform`` is neither a variable nor an atom:
|        ``type_error(atom,Platform)``
|    ``Argument`` is neither a variable nor an atom:
|        ``type_error(atom,Argument)``
|    ``Platform`` is an atom but neither ``posix`` nor ``windows``:
|        ``domain_error(souffle_shell_platform,Platform)``
|    ``Argument`` is an atom but contains a null character:
|        ``domain_error(souffle_shell_argument,Argument)``

.. index:: run/10

``run/10``
^^^^^^^^^^

Runs the CLI using an owned directory and separate UTF-8 capture files, materializing EDB facts and reading back requested ``.output`` relation files before cleanup, returning only after cleanup.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``run(Executable,Arguments,ProgramSource,FactsSpec,OutputRelations,Codes,Diagnostics,RelationCodes,RawStatus,NormalizedStatus)``
| **Mode and number of proofs:**
|    ``run(+atom,+list(atom),+compound,+compound,+list(atom),-list(integer),-list(integer),-list(compound),-term,-compound)`` - ``one_or_error``

| **Exceptions:**
|    ``Executable``, ``Arguments``, ``ProgramSource``, ``FactsSpec``, or ``OutputRelations`` is a variable:
|        ``instantiation_error``
|    An element of the list ``Arguments`` or ``OutputRelations`` is a variable:
|        ``instantiation_error``
|    ``Executable`` is neither a variable nor an atom:
|        ``type_error(atom,Executable)``
|    ``Arguments`` is neither a variable nor a list:
|        ``type_error(list,Arguments)``
|    An element of the list ``Arguments`` is neither a variable nor an atom:
|        ``type_error(atom,Argument)``
|    An element of the list ``OutputRelations`` is neither a variable nor an atom:
|        ``type_error(atom,Name)``
|    ``ProgramSource`` is neither ``file(Path)`` nor ``codes(Codes)``:
|        ``domain_error(souffle_process_source,ProgramSource)``
|    ``FactsSpec`` is neither ``none``, ``external(Path)``, nor ``materialize(Pairs)``:
|        ``domain_error(souffle_facts_spec,FactsSpec)``
|    A materialized facts row has a symbol column value containing a tab or newline character, or a value that is not an integer, float, or atom:
|        ``domain_error(souffle_facts_value,Value)``
|    An argument contains a null character:
|        ``domain_error(souffle_shell_argument,Argument)``
|    A launcher dependency does not exist:
|        ``existence_error(command,Command)``
|    A source or capture file does not exist:
|        ``existence_error(source_sink,Path)``
|    A source or capture file cannot be opened:
|        ``permission_error(open,source_sink,Path)``
|    An owned directory cannot be found during cleanup:
|        ``existence_error(directory,Directory)``
|    An owned file or directory cannot be removed:
|        ``permission_error(delete,source_sink,Path)``
|    A character sequence is not valid UTF-8:
|        ``representation_error(utf_8)``
|    A launcher operation fails:
|        ``souffle_transport(Stage,Status,Details)``
