``decode/7``
^^^^^^^^^^^^

Decodes captured stdout and process metadata into a list of collected ``smt_result(Status, Model, Properties)`` terms, one per ``check-sat``/``check-sat-assuming`` response, in order. Each response is classified by its shape (status atom, model, unsat core, or get-value pairs), so the decoder does not need the originating statement list and supports every source kind.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``decode(Solver,Codes,RawStatus,NormalizedStatus,Diagnostics,SourceMap,Results)``
| **Mode and number of proofs:**
|    ``decode(+atom,+list(code),+term,+compound,+list(code),+list(compound),-list(compound))`` - ``one_or_error``

| **Exceptions:**
|    ``Solver`` is not a ground term:
|        ``instantiation_error``
|    ``Solver`` is neither a variable nor an atom:
|        ``type_error(atom,Solver)``
|    ``Codes`` is a partial list or a list with an element ``Element`` which is a variable:
|        ``instantiation_error``
|    ``Codes`` is neither a partial list nor a list of character codes:
|        ``type_error(codes,Codes)``
|    ``Codes`` contains an unrecognized character or an unbalanced parenthesis:
|        ``domain_error(smt_output,Field-Value)``
|    A model, unsat core, or get-value response appears before any status response:
|        ``domain_error(smt_output,Response-unexpected)``
|    The solver reported an ``(error ...)`` response:
|        ``smt_solver_reported_error(Message)``
|    ``RawStatus`` is not a ground term:
|        ``instantiation_error``
|    ``NormalizedStatus`` is not a ground term:
|        ``instantiation_error``
|    ``NormalizedStatus`` is neither a variable nor one of ``exit(Code)``, ``unknown(Details)``, nor ``killed(Details)``:
|        ``domain_error(smt_process_status,NormalizedStatus)``
|    No response was parsed and the process did not exit cleanly:
|        ``domain_error(smt_process_status,NormalizedStatus)``
|    ``Diagnostics`` is a partial list or a list with an element ``Element`` which is a variable:
|        ``instantiation_error``
|    ``Diagnostics`` is neither a partial list nor a list of character codes:
|        ``type_error(codes,Diagnostics)``
|    ``SourceMap`` is a partial list or a list with an element ``Element`` which is a variable:
|        ``instantiation_error``
|    ``SourceMap`` is neither a variable nor a list:
|        ``type_error(list,SourceMap)``
