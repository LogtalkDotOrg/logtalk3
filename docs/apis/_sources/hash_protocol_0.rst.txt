``hash_protocol``
=================

``hash/2``
^^^^^^^^^^

Computes the hash for a list of bytes.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``hash(Bytes,Hash)``
| **Mode and number of proofs:**
|    ``hash(+list(byte),--atom)`` - ``one_or_error``

| **Exceptions:**
|    The key, digest size, or output length is not sufficiently instantiated::
|        ``instantiation_error``
|    The digest size is invalid for BLAKE2::
|        ``domain_error(blake2_digest_size,DigestSize)``
|    The key is ground but invalid for BLAKE2::
|        ``domain_error(blake2_key,Key)``
|    The key is ground but not a list of 16 bytes for SipHash::
|        ``domain_error(siphash_key,Key)``
|    The output length is ground but not a nonnegative integer for SHAKE::
|        ``domain_error(shake_output_size,OutputBytes)``
