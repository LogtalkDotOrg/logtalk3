.. index:: item_content/2
.. _item_content_dataset_protocol/0::item_content/2:

``item_content/2``
^^^^^^^^^^^^^^^^^^

Enumerates exactly one content descriptor for each catalog item. Descriptors are ``features(Occurrences)`` with ground feature occurrences or ``vector(Pairs)`` with unique ground feature keys and finite nonnegative weights. Empty lists are allowed. All items use the same descriptor kind.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``item_content(Item,Content)``
| **Mode and number of proofs:**
|    ``item_content(-atomic,-compound)`` - ``zero_or_more``
|    ``item_content(+atomic,-compound)`` - ``one``
