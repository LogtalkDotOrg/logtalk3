.. index:: serialize/2
.. _wmc_program/0::serialize/2:

``serialize/2``
^^^^^^^^^^^^^^^

Serializes ground canonical statements to CNF character codes (``p cnf`` header, ``c p weight`` lines when the problem is weighted, and clauses), assigning sequential variable numbers by first occurrence across clauses and weights. In a weighted problem, both literals of every variable get an explicit weight (1 when unspecified).

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``serialize(Statements,Codes)``
| **Mode and number of proofs:**
|    ``serialize(+list,-list(code))`` - ``one_or_error``

| **Exceptions:**
|    ``Statements`` is a partial list or a list with an element ``Statement`` which is a variable:
|        ``instantiation_error``
|    ``Statements`` is neither a partial list nor a list:
|        ``type_error(list,Statements)``
|    An element ``Statement`` of the list ``Statements`` is not a valid statement:
|        ``domain_error(wmc_statement,Statement)``
|    The weight of a literal is given more than once:
|        ``domain_error(wmc_duplicate_weight,Literal)``

.. index:: serialize/4
.. _wmc_program/0::serialize/4:

``serialize/4``
^^^^^^^^^^^^^^^

Serializes statements with origins and returns ``line(Start, End, Origin)`` source-map entries for the statements that generate lines (weight and probability statements do not).

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``serialize(Statements,Origins,Codes,SourceMap)``
| **Mode and number of proofs:**
|    ``serialize(+list,+list,-list(code),-list(compound))`` - ``one_or_error``

| **Exceptions:**
|    ``Statements`` is a partial list or a list with an element ``Statement`` which is a variable:
|        ``instantiation_error``
|    ``Statements`` is neither a partial list nor a list:
|        ``type_error(list,Statements)``
|    An element ``Statement`` of the list ``Statements`` is not a valid statement:
|        ``domain_error(wmc_statement,Statement)``
|    The weight of a literal is given more than once:
|        ``domain_error(wmc_duplicate_weight,Literal)``
|    ``Origins`` has an element that is neither ``unknown`` nor a valid ``source(File, Start, End)`` term, or its length differs from ``Statements``:
|        ``domain_error(wmc_origins,Origins)``
