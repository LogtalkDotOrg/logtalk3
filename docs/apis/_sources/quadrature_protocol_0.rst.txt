.. index:: integrate/3
.. _quadrature_protocol/0::integrate/3:

``integrate/3``
^^^^^^^^^^^^^^^

Integrates the function over the given finite interval using default options.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``integrate(Lower,Upper,Integral)``
| **Mode and number of proofs:**
|    ``integrate(+number,+number,-number)`` - ``one_or_error``

| **Exceptions:**
|    An integration bound is a variable:
|        ``instantiation_error``
|    An integration bound is not a number:
|        ``type_error(number,Bound)``
|    The function returns a non-numeric value:
|        ``domain_error(function_value,Value)``

``integrate/4``
^^^^^^^^^^^^^^^

Integrates the function over the given finite interval using the given options.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``integrate(Lower,Upper,Integral,Options)``
| **Mode and number of proofs:**
|    ``integrate(+number,+number,-number,+list(compound))`` - ``one_or_error``

| **Exceptions:**
|    An integration bound or ``Options`` is a variable:
|        ``instantiation_error``
|    An integration bound is not a number:
|        ``type_error(number,Bound)``
|    ``Options`` is not a list or contains an invalid option:
|        ``domain_error(options,Options)``

|        ``domain_error(function_value,Value)``
