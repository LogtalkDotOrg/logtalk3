**protocol**

``wmc_protocol``
================

Protocol for weighted model counting using external Ganak and SharpSAT-TD CLI counters or a reference counter written in Logtalk, CNF source generation, and result inspection.

.. index:: solve/2
.. _wmc_protocol/0::solve/2:

``solve/2``
^^^^^^^^^^^

Computes the weighted model count of a source with default options and returns a collected result after cleanup. Valid sources are ``object(Object)``, ``terms(Statements)``, ``codes(Codes)``, and ``file(Path)``.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``solve(Source,Result)``
| **Mode and number of proofs:**
|    ``solve(+compound,-compound)`` - ``one_or_error``

| **Exceptions:**
|    ``Source`` is not a ground term:
|        ``instantiation_error``
|    ``Source`` is ground but not a supported source, or is ``object(Object)`` where ``Object`` does not implement ``wmc_problem_protocol``:
|        ``domain_error(wmc_source,Source)``
|    A statement is not a valid statement:
|        ``domain_error(wmc_statement,Statement)``
|    The selected solver executable or a shell dependency does not exist:
|        ``existence_error(command,Command)``
|    A launcher operation fails:
|        ``wmc_transport(Stage,Status,Details)``
|    Solver output is invalid or inconsistent with its exit status:
|        ``wmc_solver_error(Formal,Status,Diagnostics,SourceMap)``

.. index:: solve/3
.. _wmc_protocol/0::solve/3:

``solve/3``
^^^^^^^^^^^

Computes the weighted model count of a source using the ``solver/1``, ``executable/1``, ``time_limit/1``, ``decomposition_time/1``, and ``embed_variables/1`` options. Repeated options use the first occurrence. Valid sources are ``object(Object)``, ``terms(Statements)``, ``codes(Codes)``, and ``file(Path)``. File sources are read and passed to the solver as a file named ``problem.cnf``.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``solve(Source,Result,Options)``
| **Mode and number of proofs:**
|    ``solve(+compound,-compound,+list(compound))`` - ``one_or_error``

| **Exceptions:**
|    ``Source`` is not a ground term:
|        ``instantiation_error``
|    ``Source`` is ground but not a supported source, or is ``object(Object)`` where ``Object`` does not implement ``wmc_problem_protocol``:
|        ``domain_error(wmc_source,Source)``
|    A statement is not a valid statement:
|        ``domain_error(wmc_statement,Statement)``
|    ``Options`` is a variable:
|        ``instantiation_error``
|    ``Options`` is neither a variable nor a list:
|        ``type_error(list,Options)``
|    An element ``Option`` of the list ``Options`` is a compound term but not a valid option:
|        ``domain_error(option,Option)``
|    The selected solver executable or a shell dependency (e.g., the ``timeout`` command) does not exist:
|        ``existence_error(command,Command)``
|    A launcher operation fails:
|        ``wmc_transport(Stage,Status,Details)``
|    Solver output is invalid or inconsistent with its exit status:
|        ``wmc_solver_error(Formal,Status,Diagnostics,SourceMap)``
