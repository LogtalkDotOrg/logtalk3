**object**

``issue_creator``
=================

Support for automatically creating bug report issues for failed tests in GitHub, GitLab, Azure DevOps, Gitea, Jira, or Linear servers.

| **Availability:** 
|    ``logtalk_load(issue_creator(loader))``

| **Author:** Paulo Moura
| **Version:** 0:14:0
| **Date:** 2026-10-27

| **Compilation flags:**
|    ``static, context_switching_calls``


| **Provides:**
|    :ref:`logtalk::message_hook/4 <logtalk/0::message_hook/4>`
| **Uses:**
|    :ref:`base64 <base64/0>`
|    :ref:`git <git/0>`
|    :ref:`list <list/0>`
|    :ref:`os <os/0>`
|    :ref:`term_io <term_io/0>`
|    :ref:`user <user/0>`
|    :ref:`utf_16le <utf_16le/0>`

| **Remarks:**

   - Usage: This tool is automatically loaded and used from the ``logtalk_tester`` automation script when using its ``-b`` option. See the script man page for details.

| **Inherited public predicates:**
|    (none)
