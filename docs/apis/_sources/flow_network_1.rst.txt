**object**

``flow_network(Dictionary)``
============================

* ``Dictionary`` - Dictionary object (e.g., ``avltree``, ``rbtree``, ``bintree``, or ``splaytree``).


Flow network construction and inspection. The network is an opaque term. Each input arc is stored as a residual pair of arcs: a forward arc with identifier ``2*I`` and a reverse arc with identifier ``2*I+1`` (``I`` being the zero-based position of the arc in the input list), where the reverse arc has zero initial residual capacity and the negated cost. The parametric object parameter is the dictionary object used for the representation and must be the same one used by the flow algorithm objects.
