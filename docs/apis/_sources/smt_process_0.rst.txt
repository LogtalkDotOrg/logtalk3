.. index:: quote/3

``quote/3``
^^^^^^^^^^^

Quotes an atom as one POSIX shell or Windows PowerShell literal, without interpolation.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``quote(Platform,Argument,Quoted)``
| **Mode and number of proofs:**
|    ``quote(+atom,+atom,-atom)`` - ``one_or_error``

| **Exceptions:**
|    ``Platform`` is a variable:
|        ``instantiation_error``
|    ``Platform`` is neither a variable nor an atom:
|        ``type_error(atom,Platform)``
|    ``Platform`` is an atom but neither ``posix`` nor ``windows``:
|        ``domain_error(smt_shell_platform,Platform)``
|    ``Argument`` is a variable:
|        ``instantiation_error``
|    ``Argument`` is neither a variable nor an atom:
|        ``type_error(atom,Argument)``
|    ``Argument`` is an atom but contains a null character:
|        ``domain_error(smt_shell_argument,Argument)``

.. index:: run/7

``run/7``
^^^^^^^^^

Runs the CLI using an owned directory and separate UTF-8 output files, returning only after cleanup.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``run(Executable,Arguments,Source,Codes,Diagnostics,RawStatus,NormalizedStatus)``
| **Mode and number of proofs:**
|    ``run(+atom,+list(atom),+compound,-list(code),-list(code),-term,-compound)`` - ``one_or_error``

| **Exceptions:**
|    ``Executable`` is a variable:
|        ``instantiation_error``
|    ``Executable`` is neither a variable nor an atom:
|        ``type_error(atom,Executable)``
|    ``Arguments`` is a partial list or a list with an element ``Argument`` which is a variable:
|        ``instantiation_error``
|    ``Arguments`` is neither a variable nor a list:
|        ``type_error(list(atom),Arguments)``
|    An element ``Argument`` of the list ``Arguments`` is neither a variable nor an atom:
|        ``type_error(atom,Argument)``
|    ``Executable`` or an element ``Argument`` of the list ``Arguments`` contains a null character:
|        ``domain_error(smt_shell_argument,Argument)``
|    ``Source`` is not a ground term:
|        ``instantiation_error``
|    ``Source`` is neither ``file(Path)`` nor ``codes(Codes)``:
|        ``domain_error(smt_process_source,Source)``
|    A launcher dependency does not exist:
|        ``existence_error(command,Command)``
|    A source or capture file does not exist:
|        ``existence_error(source_sink,Path)``
|    A source or capture file cannot be opened:
|        ``permission_error(open,source_sink,Path)``
|    An owned directory cannot be found during cleanup:
|        ``existence_error(directory,Directory)``
|    An owned file or directory cannot be removed:
|        ``permission_error(delete,source_sink,Path)``
|    A character sequence is not valid UTF-8:
|        ``representation_error(utf_8)``
|    A launcher operation fails:
|        ``smt_transport(Stage,Status,Details)``
