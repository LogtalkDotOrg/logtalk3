.. index:: solve/2
.. _problog_protocol/0::solve/2:

``solve/2``
^^^^^^^^^^^

Runs exact inference with default options. Valid sources are ``object(Object)``, ``terms(Statements)``, ``codes(Codes)``, and ``file(Path)``. Returns a ground collected result after cleanup.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``solve(Source,Result)``
| **Mode and number of proofs:**
|    ``solve(+compound,-compound)`` - ``one_or_error``

| **Exceptions:**
|    ``Source`` is not ground:
|        ``instantiation_error``
|    ``Source`` is ground but invalid:
|        ``domain_error(problog_source,Source)``
|    An executable cannot be resolved:
|        ``existence_error(command,Command)``
|    A transport operation fails:
|        ``problog_transport(Stage,Status,Details)``
|    Inference fails or produces invalid output:
|        ``problog_solver_error(Formal,Status,Diagnostics,SourceMap)``

.. index:: solve/3
.. _problog_protocol/0::solve/3:

``solve/3``
^^^^^^^^^^^

Runs exact inference with the given options options. Repeated options use the first occurrence.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``solve(Source,Result,Options)``
| **Mode and number of proofs:**
|    ``solve(+compound,-compound,+list(compound))`` - ``one_or_error``

| **Exceptions:**
|    ``Source`` is not ground:
|        ``instantiation_error``
|    ``Source`` is ground but invalid:
|        ``domain_error(problog_source,Source)``
|    ``Options`` is a variable:
|        ``instantiation_error``
|    ``Options`` is neither a variable nor a list:
|        ``type_error(list,Options)``
|    An element ``Option`` of the list ``Options`` is a variable:
|        ``instantiation_error``
|    An element ``Option`` of the list ``Options`` is neither a variable nor a compound term:
|        ``type_error(compound,Option)``
|    An element ``Option`` of the list ``Options`` is a compound term but not a valid option:
|        ``domain_error(option,Option)``
|    An executable cannot be resolved:
|        ``existence_error(command,Command)``
|    A transport operation fails:
|        ``problog_transport(Stage,Status,Details)``
|    Inference fails or produces invalid output:
|        ``problog_solver_error(Formal,Status,Diagnostics,SourceMap)``

``print_program/1``
^^^^^^^^^^^^^^^^^^^

Prints character codes to the current output without adding a newline.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``print_program(Codes)``
| **Mode and number of proofs:**
|    ``print_program(+list(integer))`` - ``one_or_error``

| **Exceptions:**
|    ``Codes`` is a partial list or a list with an element ``Element`` which is a variable:
|        ``instantiation_error``
|    ``Codes`` is is neither a partial list nor a list:
|        ``type_error(codes,Codes)``
|    An element ``Element`` of the ``Codes`` list is neither a variable nor an integer:
|        ``type_error(integer,Element)``
|    An element ``Element`` of the ``Codes`` list is an integer but not a valid character code:
|        ``domain_error(character_code,Element)``
