``max_sat_protocol``

.. index:: solve/2
.. _max_sat_protocol/0::solve/2:

``solve/2``
^^^^^^^^^^^

Solves a source with default options using the external MaxSAT solver CLI and returns a collected result after cleanup. Valid sources are ``object(Object)``, ``terms(Statements)``, ``codes(Codes)``, and ``file(Path)``.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``solve(Source,Result)``
| **Mode and number of proofs:**
|    ``solve(+compound,-compound)`` - ``one_or_error``

| **Exceptions:**
|    ``Source`` is not a ground term:
|        ``instantiation_error``
|    ``Source`` is ground but not a supported source, or is ``object(Object)`` where ``Object`` does not implement ``max_sat_problem_protocol``:
|        ``domain_error(max_sat_source,Source)``
|    A statement is not a valid statement:
|        ``domain_error(max_sat_statement,Statement)``
|    The selected solver executable or a shell dependency does not exist:
|        ``existence_error(command,Command)``
|    A launcher operation fails:
|        ``max_sat_transport(Stage,Status,Details)``
|    Solver output is invalid or inconsistent with its exit status:
|        ``max_sat_solver_error(Formal,Status,Diagnostics,SourceMap)``

.. index:: solve/3

``solve/3``
^^^^^^^^^^^

Solves a source using the ``solver/1``, ``executable/1``, ``time_limit/1``, ``anytime/1``, and ``wcnf_format/1`` options. Repeated options use the first occurrence. Valid sources are ``object(Object)``, ``terms(Statements)``, ``codes(Codes)``, and ``file(Path)``. File sources are read and passed to the solver as a ``.wcnf`` file as some solvers select the input format from the file name extension.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``solve(Source,Result,Options)``
| **Mode and number of proofs:**
|    ``solve(+compound,-compound,+list(compound))`` - ``one_or_error``

| **Exceptions:**
|    ``Source`` is not a ground term:
|        ``instantiation_error``
|    ``Source`` is ground but not a supported source, or is ``object(Object)`` where ``Object`` does not implement ``max_sat_problem_protocol``:
|        ``domain_error(max_sat_source,Source)``
|    A statement is not a valid statement:
|        ``domain_error(max_sat_statement,Statement)``
|    ``Options`` is a variable:
|        ``instantiation_error``
|    ``Options`` is neither a variable nor a list:
|        ``type_error(list,Options)``
|    An element ``Option`` of the list ``Options`` is a compound term but not a valid option:
|        ``domain_error(option,Option)``
|    The selected solver executable or a shell dependency does not exist:
|        ``existence_error(command,Command)``
|    A launcher operation fails:
|        ``max_sat_transport(Stage,Status,Details)``
|    Solver output is invalid or inconsistent with its exit status:
|        ``max_sat_solver_error(Formal,Status,Diagnostics,SourceMap)``

.. index:: cost/2
.. _max_sat_protocol/0::cost/2:

``cost/2``
^^^^^^^^^^

Returns the cost (sum of the weights of the falsified soft clauses) of the collected model. The cost is optimal for an ``optimal`` result and an upper bound for a ``satisfiable`` (best-known) result. Fails when the result has no cost.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``cost(Result,Cost)``
| **Mode and number of proofs:**
|    ``cost(+compound,-integer)`` - ``zero_or_one``
