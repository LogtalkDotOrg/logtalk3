.. index:: solve/2
.. _clingo_protocol/0::solve/2:

``solve/2``
^^^^^^^^^^^

Solves a source with default options using the external Clingo CLI and returns a collected result after cleanup.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``solve(Source,Result)``
| **Mode and number of proofs:**
|    ``solve(+compound,-compound)`` - ``one_or_error``

| **Exceptions:**
|    ``Source`` or a provider statement is insufficiently instantiated:
|        ``instantiation_error``
|    A source list has an invalid type:
|        ``type_error(list,Input)``
|    ``Codes`` is not a character-code list:
|        ``type_error(codes,Codes)``
|    ``Path`` is not an atom:
|        ``type_error(atom,Path)``
|    ``Source`` is not supported:
|        ``domain_error(clingo_source,Source)``
|    A provider statement is invalid:
|        ``domain_error(clingo_statement,Statement)``
|    A provider origin is invalid:
|        ``domain_error(clingo_origins,Origins)``
|    A launcher argument contains a null character:
|        ``domain_error(clingo_shell_argument,Argument)``
|    Clingo or a shell dependency cannot be resolved:
|        ``existence_error(command,Command)``
|    A source or capture file cannot be accessed:
|        ``existence_error(source_sink,Path)``
|    A source or capture file cannot be opened:
|        ``permission_error(open,source_sink,Path)``
|    An owned directory cannot be found during cleanup:
|        ``existence_error(directory,Directory)``
|    An owned file or directory cannot be removed:
|        ``permission_error(delete,source_sink,Path)``
|    A character sequence is not valid UTF-8:
|        ``representation_error(utf_8)``
|    A launcher operation fails:
|        ``clingo_transport(Stage,Status,Details)``
|    Solver output is invalid or inconsistent with its exit status:
|        ``clingo_solver_error(Formal,Status,Diagnostics,SourceMap)``

``program/1``
^^^^^^^^^^^^^

Generates and prints ASP source to the current output, equivalent to ``program/2`` followed by ``print_program/1``, without invoking Clingo.

| **Compilation flags:**
|    ``static``

| **Template:**
|    ``program(Source)``
| **Mode and number of proofs:**
|    ``program(+compound)`` - ``one_or_error``

| **Exceptions:**
|    ``Source`` or a provider statement is insufficiently instantiated:
|        ``instantiation_error``
|    ``Statements`` is not a list:
|        ``type_error(list,Statements)``
|    ``Codes`` is not a character-code list:
|        ``type_error(codes,Codes)``
|    A character code is not an integer:
|        ``type_error(integer,Code)``
|    ``Path`` is not an atom:
|        ``type_error(atom,Path)``
|    A character code is outside the supported range:
|        ``domain_error(character_code,Code)``
|    ``Source`` is not a supported source or its object does not implement the provider protocol:
|        ``domain_error(clingo_source,Source)``
|    A provider statement is invalid:
|        ``domain_error(clingo_statement,Statement)``
|    A provider origin is invalid:
|        ``domain_error(clingo_origins,Origins)``
|    ``Path`` does not exist:
|        ``existence_error(source_sink,Path)``
|    ``Path`` cannot be opened for reading:
|        ``permission_error(open,source_sink,Path)``
|    The current output stream does not allow writing:
|        ``permission_error(output,stream,Stream)``
